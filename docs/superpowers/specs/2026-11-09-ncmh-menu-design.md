# 국립정신건강센터 직원 식단 보기 사이트 — 설계

작성일: 2026-11-09

## 왜 만드나

국립정신건강센터 공지사항(https://www.ncmh.go.kr/ncmh/board/boardList.do?fno=37&menu_cd=01_01)에 매주 다음 주 직원 식단표가 텍스트 파일과 jpg로 올라온다. 매번 공지를 찾아 들어가 파일을 여는 게 귀찮다. 휴대폰으로 열면 오늘 메뉴가 바로 보이는 사이트를 만들어 본인과 동료들이 같이 쓴다.

## 목표

- 휴대폰으로 주소를 열면 오늘 메뉴가 바로 보인다.
- 요일을 눌러 이번 주 다른 날 메뉴를 볼 수 있다.
- 사람이 손대지 않아도 매주 새 식단으로 바뀐다(수정본 재업로드 포함).
- 동료에게 주소만 알려주면 누구나 볼 수 있다.

## 하지 않는 것

- 로그인, 글쓰기, 댓글, 알림, 앱 설치.
- 원산지·알레르기 상세 정보 화면(원문에도 "일일메뉴 게시판에 별도 표시"라고만 되어 있다).
- 지난 식단 보관/검색.
- 원본 jpg 표시(텍스트로 충분하다고 판단, 사용자가 시안 C를 고르지 않음).

## 실패로 보는 경우

- 매주 누군가 직접 올려야 한다 → 공지 들어가는 것보다 나을 게 없다.
- 오늘 날짜인데 지난주 메뉴나 빈 화면이 보인다(안내 없이).
- 휴대폰에서 글씨가 작거나 가로로 밀린다.

## 원본 데이터 (2026-11-09 직접 확인)

- 공지 목록: `https://www.ncmh.go.kr/ncmh/board/boardList.do?fno=37&menu_cd=01_01` — 로그인 없이 열림. 식단 글 제목은 `2026년 11월 2주차 직원 식단표` 형식. 다른 공지와 섞여 있으므로 제목에 "직원 식단표"가 든 가장 위 글을 고른다. 글 링크는 `boardView.do?no=<글번호>&fno=37...`.
- 글 본문 HTML 안에 첨부가 `fn_fileDown('<파일이름>.txt','/2026/11/20261106094659003235_2.txt', ...)` 형태로 들어 있다. 파일이름에 "텍스트파일"이 들어가고 `.txt`로 끝나는 첨부를 쓴다.
- 텍스트 파일은 `https://www.ncmh.go.kr/static/jsp/download_image.jsp?physical_name=<위 경로>`로 GET하면 로그인 없이 받아진다(UTF-8). 화면의 정식 다운로드(`/board/doFileDownload.do` POST)는 세션 없이 빈 응답이 왔다.
- 업로드 시점: 10/22(목), 10/29(목) 확인. 11월 2주차는 11/06 09:46에 `_수정.txt`로 다시 올라옴 → 수정본이 같은 글에 교체되어 올라온다.
- 파일 내용 예(11월 2주차):

```
기간: 11월 9일(월) ~ 11월 15일(일)
중식: 평일 11:30~13:00, 주말 11:30~12:20
석식: 16:20~17:10 운영(직원전용 운영)
중,석식 동일메뉴 제공됩니다.

11월 9일(월)
주메뉴: 어묵채잔치국수
밥: 흰쌀밥
국 및 반찬: 임꺽정떡갈비, 청포묵김가루무침, 얼갈이겉절이, 깍두기
PLUS 코너: 숭늉
TAKE OUT: 감자샐러드
```

- 주마다 형식이 조금 다르다(11월 1주차와 비교):
  - 날짜 줄이 `11월 9일(월)`일 때도, `[11월 2일(월)]`일 때도 있다.
  - `밥:` 줄이 없는 날이 있다.
  - 메뉴에 `♥미니핫도그&케찹♥`, `*`(알레르기 표시) 같은 기호가 섞인다.
  - 주말 `TAKE OUT: 운영없음`.
  - 토요일에 `밥: 콩나물국`처럼 항목이 어긋난 경우도 있다 → 원문 그대로 보여준다(고치려 하지 않는다).

## 화면 (사용자 확정: 시안 A+ "화이트")

휴대폰 세로 화면 기준. 흰 바탕, Pretendard 글꼴.

1. 맨 위 상태 알약: 시간대에 따라
   - 중식 시간 → "지금 중식 시간 · 13:00까지"(주말은 12:20까지)
   - 석식 시간 → "지금 석식 시간 · 17:10까지"
   - 그 외 → 다음 식사 시작 시각(예: "중식 11:30부터")
   - 다른 요일을 보고 있을 땐 숨김. 시각은 파일의 운영시간 줄에서 읽고, 못 읽으면 위 값을 기본값으로 쓴다.
2. 날짜: "11월 9일 월요일"
3. 큰 문장: "오늘 점심은 / **어묵채잔치국수**"(다른 날을 볼 땐 "수요일 점심은"). 주메뉴가 `A-… / B-…`면 두 줄로.
4. "밥 · 국 및 반찬": 둥근 칩. 밥 칩은 노란 계열로 구분. 없는 항목은 생략.
5. PLUS 코너 / TAKE OUT: 나란히 두 칸.
6. 화면 아래 떠 있는 요일 막대(월~일). 오늘이 기본 선택. 선택된 요일은 검은 원.
7. 다음 주 식단이 이미 있으면 요일 막대 옆/위에 "다음 주 ›"로 넘어갈 수 있다.
8. 하단 작은 글씨: 원문 공지 링크, 마지막으로 가져온 시각, "식단은 사정에 따라 바뀔 수 있어요".

빈 상태: 오늘 날짜가 들어 있는 식단이 없으면 "아직 이번 주 식단이 올라오지 않았어요" + 센터 공지 바로가기.

시안 원본: `layout-v3.html`의 A+ 카드(브레인스토밍 세션 화면). 색: 강조 #3182f6, 글자 #191f28, 보조 #8b95a1, 칩 배경 #f4f6f8.

날짜 판단은 항상 한국 시간(Asia/Seoul) 기준.

## 만드는 방법 (내 판단, 사용자 승인)

- **호스팅**: GitHub 공개 저장소 + GitHub Pages. 무료, 주소 공유만 하면 된다. 계정 `jongseP`(gh 로그인 확인됨).
- **자동 갱신**: GitHub Actions 예약 실행이 스크립트를 돌려
  1. 공지 목록에서 "직원 식단표" 글 최신 2개를 찾고
  2. 각 글의 `.txt` 첨부를 받아
  3. 요일별 JSON(`data/menu.json`)으로 바꿔
  4. 내용이 바뀌었을 때만 커밋 → Pages가 다시 배포.
  - 실행 주기: 매일 몇 번(예: 한국 시간 07:00, 10:00, 13:00, 17:00). 목~월에 몰아 돌릴 수도 있지만 하루 몇 번이면 충분하고 단순하다.
- **화면**: 정적 HTML 한 장 + `menu.json`을 읽는 소량의 JS. 프레임워크·빌드 도구 없음.
- **파싱 실패 시**: 기존 `menu.json`을 덮어쓰지 않고 Actions가 실패로 끝나게 한다(GitHub이 메일로 알려 줌).

## 확인하지 못한 위험

- **GitHub Actions 서버(해외 IP)에서 ncmh.go.kr 접속이 되는지 확인하지 못했다.** 정부 사이트가 해외 접속을 막는 경우가 있다. 구현 첫 단계에서 Actions로 한 번 받아보고, 막히면 대안을 사용자와 정한다(예: 이 PC의 Windows 작업 스케줄러로 가져와 push).
- 센터가 게시판 주소나 파일 형식을 바꾸면 깨진다 → 위 실패 처리로 알게 된다.
