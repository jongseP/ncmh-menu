# 직원 식단 보기 사이트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 국립정신건강센터 공지의 직원 식단표를 자동으로 가져와, 휴대폰에서 오늘 메뉴를 바로 보여주는 정적 사이트.

**Architecture:** Python 스크립트(표준 라이브러리만)가 공지 → 글 → `.txt` 첨부를 받아 `data/menu.json`으로 바꾼다. GitHub Actions가 하루 4번 이 스크립트를 돌리고 바뀌었을 때만 커밋한다. `index.html` 한 장이 `menu.json`을 읽어 화면을 그린다(GitHub Pages).

**Tech Stack:** Python 3.12 표준 라이브러리, 순수 HTML/CSS/JS(프레임워크·빌드 없음), Pretendard(jsDelivr), GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-11-09-ncmh-menu-design.md`

## Global Constraints

- 새 의존성 없음: Python 표준 라이브러리, 프론트는 Pretendard CSS 외 외부 스크립트 없음.
- 날짜·시각 판단은 항상 `Asia/Seoul`.
- 목록 URL: `https://www.ncmh.go.kr/ncmh/board/boardList.do?fno=37&menu_cd=01_01`
- 글 URL: `https://www.ncmh.go.kr/ncmh/board/boardView.do?no=<no>&fno=37&menu_cd=01_01&bn=newsView`
- 파일 URL: `https://www.ncmh.go.kr/static/jsp/download_image.jsp?physical_name=<path>` (UTF-8)
- 식단 글 판별: 제목에 `직원 식단표`. 첨부 판별: 파일이름이 `.txt`로 끝남.
- 운영시간 기본값: 중식 평일 `11:30~13:00`, 주말 `11:30~12:20`, 석식 `16:20~17:10`.
- 색: 강조 `#3182f6`, 글자 `#191f28`, 보조 `#8b95a1`, 칩 배경 `#f4f6f8`, 밥 칩 `#fff8e6`/`#8a6100`.
- 메뉴 텍스트는 원문 그대로 보여준다(`♥`, `*`, 어긋난 항목 포함, 고치지 않음).
- 파싱 실패 시 기존 `data/menu.json`을 덮어쓰지 않고 종료코드 1.

## Review Focus

1. 12월 말 주차(제목 `2026년 12월 5주차`)에 1월 날짜가 섞임 → 1월 날짜는 연도+1. (Task 1 테스트)
2. 날짜 줄 두 형식 `11월 9일(월)` / `[11월 2일(월)]`, `밥:` 줄 없는 날 → 둘 다 읽고 `rice`는 `null`. (Task 1 테스트, 실제 원문 fixture)
3. 오늘 날짜가 어느 주에도 없음(목요일 전 공백, 가져오기 실패) → 빈 상태 안내 + 공지 링크. (Task 3 테스트)
4. 텍스트에서 날짜가 0개 나옴(형식 변경) → `menu.json` 그대로, 종료코드 1. (Task 2 테스트)
5. 주메뉴 `A-고추장닭갈비 / B-치킨까스&머스타드` → 두 줄로 표시. (Task 1에서 `main`을 `/` 기준 리스트로)

### Task 1: 식단 텍스트 파서

**Files:**
- Create: `fetch_menu.py`
- Create: `tests/test_parse.py`
- Exists: `tests/fixtures/2026-11-w1.txt`, `tests/fixtures/2026-11-w2.txt` (실제 원문, 이미 저장됨)

**Interfaces:**
- Produces: `parse_menu(text: str, title: str) -> dict`
  ```
  {"title": str,
   "hours": {"lunch_weekday": "11:30~13:00", "lunch_weekend": "11:30~12:20", "dinner": "16:20~17:10"},
   "days": [{"date": "2026-11-09", "main": ["어묵채잔치국수"], "rice": "흰쌀밥" | None,
             "sides": ["임꺽정떡갈비", ...], "plus": "숭늉" | None, "takeout": "감자샐러드" | None}]}
  ```
  연도는 `title`의 `(\d{4})년 (\d+)월`에서. 날짜의 월 < 제목의 월이면 연도+1. `main`은 ` / `로 나누고 앞뒤 공백 제거. `sides`는 `, `로 나눔. 시간 줄을 못 읽으면 기본값.

- [ ] **Step 1: 실패하는 테스트 작성** — `tests/test_parse.py` (plain assert, `python tests/test_parse.py`로 실행)

```python

d = w2["days"][0]
assert d == {"date": "2026-11-09", "main": ["어묵채잔치국수"], "rice": "흰쌀밥",

             "plus": "숭늉", "takeout": "감자샐러드"}
assert w2["days"][1]["main"] == ["A-고추장닭갈비", "B-치킨까스&머스타드"]
assert w2["days"][6]["date"] == "2026-11-15"
assert w2["hours"] == {"lunch_weekday": "11:30~13:00", "lunch_weekend": "11:30~12:20", "dinner": "16:20~17:10"}
```

### Task 3: 화면 (index.html, 시안 A+)

**Files:**
- Create: `index.html` (CSS·화면 그리기 JS 인라인)
- Create: `logic.js` (순수 함수 두 개, 일반 `<script src>`로 로드)
- Create: `tests/test_view.mjs` (`vm.runInThisContext(fs.readFileSync("logic.js","utf8"))`로 불러 테스트)

**Interfaces:**
- Consumes: `data/menu.json` 구조(Task 1·2).
- Produces (`logic.js`의 전역 함수):
  - `findDay(weeks, isoDate) -> {week, day} | null`
  - `statusText(now: {iso: "YYYY-MM-DD", hhmm: "HH:MM", weekend: bool}, hours) -> string | null`
    - 중식 중: `지금 중식 시간 · 13:00까지` (주말 `12:20까지`)
    - 석식 중: `지금 석식 시간 · 17:10까지`
    - 중식 전: `중식 11:30부터`, 중식~석식 사이: `석식 16:20부터`, 석식 후: `null`

- [ ] **Step 1: 실패하는 테스트** — `tests/test_view.mjs` (`node tests/test_view.mjs`)

```js
const H = {lunch_weekday:"11:30~13:00", lunch_weekend:"11:30~12:20", dinner:"16:20~17:10"};
assert.equal(statusText({iso:"2026-11-09",hhmm:"12:00",weekend:false},H), "지금 중식 시간 · 13:00까지");
assert.equal(statusText({iso:"2026-11-14",hhmm:"12:00",weekend:true},H), "지금 중식 시간 · 12:20까지");
assert.equal(statusText({iso:"2026-11-09",hhmm:"09:00",weekend:false},H), "중식 11:30부터");
assert.equal(statusText({iso:"2026-11-09",hhmm:"14:00",weekend:false},H), "석식 16:20부터");
assert.equal(statusText({iso:"2026-11-09",hhmm:"16:30",weekend:false},H), "지금 석식 시간 · 17:10까지");
assert.equal(statusText({iso:"2026-11-09",hhmm:"18:00",weekend:false},H), null);
const weeks = [{title:"t", hours:H, days:[{date:"2026-11-09", main:["어묵채잔치국수"], rice:"흰쌀밥", sides:[], plus:null, takeout:null}]}];
assert.equal(findDay(weeks,"2026-11-09").day.main[0], "어묵채잔치국수");
assert.equal(findDay(weeks,"2030-01-01"), null);
```

- [ ] **Step 3: `index.html` 작성** — 레이아웃은 스펙 "화면" 1~8번과 시안 A+ 그대로:
